#  Earthquake Analytics Dashboard

An interactive data visualization dashboard built using Streamlit to analyze earthquake data.

---

##  Features
-  Date range filtering
-  Magnitude filtering
-  KPI metrics (Total, Avg, Max)
-  Interactive map visualization
-  Charts and graphs
-  Correlation heatmap

---

## Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn
- PyDeck

---

## Project Structure
earthquake-dashboard/
│── app.py
│── Earthquake_clean.csv
│── requirements.txt
│── README.md

---

## How to Run Locally

1. Install dependencies:
pip install -r requirements.txt

2. Run the app:
streamlit run app.py
